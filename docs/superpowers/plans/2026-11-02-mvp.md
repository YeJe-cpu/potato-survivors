# Potato Survivors MVP Implementation Plan

> **For agentic workers:** implement task-by-task. Checkboxes for tracking.

**Goal:** 可本地打开的最小可玩页：移动+dash+自动开火+刷怪+升级三选一+中英+窄窗可用。

**Architecture:** Vite+TS+Canvas2D；`src/sim` 固定步进；`src/render` 画世界与 HUD；`src/input` 键鼠/触控；`index.html` 含 player meta 草稿。

**Tech Stack:** TypeScript, Vite, 原生 Canvas（无 Phaser 以控包体）

## Global Constraints
- 无 form / 无 alert；外链 `target=_blank`
- 中英字符串表；默认跟浏览器语言
- 不抄 tibo 商标与原作美术
- 不花钱部署（本阶段只本地 `npm run build` + 静态产物）

### Task 1: ✅ Scaffold
- Create Vite+TS 项目于 `/workspace/potato-survivors`
- `index.html`：全屏 canvas 容器、基础 CSS、twitter player meta 草稿、CSP meta 备注（真 CSP 放 `_headers`）
- `npm run dev` / `build` 可通

### Task 2: ✅ Sim core
- 实体：player, projectile, enemy, xpGem
- 固定 dt；playing 时推进；levelup/paused 不推进游戏时
- WASD 移动、dash 冷却、自动朝最近敌开火

### Task 3: ✅ Combat loop
- 刷怪随时间升温；击杀掉 XP；满条弹三选一（3 张卡，数字键/点击）
- 至少 3 种升级效果（伤害/射速/移速或弹数）

### Task 4: ✅ Render + HUD + touch
- 像素风简单几何；顶中计时；血条；升级卡 UI
- 窄屏虚拟摇杆（按住出现）

### Task 5: ✅ i18n + polish
- zh/en；菜单 Start；死亡/重开
- `public/_headers` 草稿；README 本地玩法

Done when: `npm run build` 成功，本地预览能玩满约 2 分钟循环。
